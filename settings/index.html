🔋 What does the EMS do?
The EMS monitors solar surplus, battery SOC, and grid power every 15 seconds and automatically controls EV chargers, heat pumps, boilers, and pool pumps — maximising self-consumption without draining the battery below the configured minimum or pulling power from the grid.
1 · Load devices
Click ↻ Reload devices (top right). The EMS reads all Homey devices. Then use the dropdowns below to assign the correct devices and capabilities to each role.
2 · Configurable sections
Inverter — Measures PV production (W). Multiple devices are summed.
Power Meter (P1) — Grid connection meter: positive = import, negative = export. Used as the basis for all control decisions.
House Consumption — Optional: direct house load meter. If omitted, the EMS calculates consumption from the energy balance (PV − Grid − Battery).
Home Batteries — Assign the SOC capability. Set a Min SOC — consumers are paused when the battery drops below this level. Use Flow Actions to create flows that force-charge, force-discharge, or limit the battery's charge/discharge power via Homey Flows.
EV Chargers — Continuous current control 6–16 A (1- or 3-phase). An anti-oscillation filter prevents rapid ramping. Flows must be linked in Homey to set the charge current.
Heat Pumps — On/off control via Flow. Configurable minimum surplus threshold. Measured power (W) is used for anti-oscillation.
Boilers / Pools — Same logic as heat pumps, with separate Start/Stop flow cards.
Priority order — Configure which device type gets surplus first: e.g. EV charger → heat pump → boiler. Lower-priority devices only receive what remains.
3 · Control via Homey Flows
The EMS decides when a device runs but never sends direct device commands — instead it fires Flow trigger cards that you link to your devices in Homey:
EV — Set charge current
Trigger "EMS wants to set charger current" → tokens amps, phase1/2/3, charger_device_id. Action: charger app "Set current".
EV — Start charging
Trigger "EMS wants to start charging" — fired once when charging activates (for charger apps that require an explicit Start command).
Heat pump — Start / Stop
Triggers "EMS wants to start heat pump" / "EMS wants to stop heat pump". Only fired when surplus ≥ minimum threshold.
Boiler — Start / Stop
Triggers "EMS wants to start boiler/heater" / "EMS wants to stop boiler/heater".
Pool — Start / Stop
Triggers "EMS wants to start pool pump" / "EMS wants to stop pool pump". On the first tick after app start no flows are fired (observation mode).
4 · Set up Flow cards
Use the ✓ Create / Update Flows button in each device section — it automatically creates the required flows in the Homey folder "_Huawei EMS". You can then open the Homey app, edit those flows, and link them to your devices.
💡 Tip — Off-peak charging: Enable Offpeak charging on the EMS device in Homey to charge EVs at full power during cheap overnight tariffs, independent of solar surplus.
