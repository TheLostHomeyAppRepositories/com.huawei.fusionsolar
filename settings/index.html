ℹ️ How does the EMS work? — Setup & Flow-based control ▾
🔋 What does the EMS do?
The EMS monitors solar surplus, battery SOC, and grid power every 15 seconds and automatically controls EV chargers, heat pumps, boilers, pool pumps, and dehumidifiers — maximising self-consumption without draining the battery below the configured minimum or pulling power from the grid. An optional Solcast solar forecast lets it hold off starting devices on a poor-forecast day to protect the battery for the evening.
1 · Load devices
Click ↻ Reload devices (top right). The EMS reads all Homey devices. Then use the dropdowns below to assign the correct devices and capabilities to each role.
2 · Configurable sections
Inverter — Measures PV production (W). Multiple devices are summed.
Power Meter (P1) — Grid connection meter: positive = import, negative = export. Used as the basis for all control decisions.
House Consumption — Optional: direct house load meter. If omitted, the EMS calculates consumption from the energy balance (PV − Grid − Battery).
Home Batteries — Assign the SOC capability and the usable capacity (kWh). Set a Normal SOC (full budget above it) and optionally a lower Reserve SOC — consumers are paused below the reserve, throttled between the two. Use Flow Actions to create flows that force-charge, force-discharge, or limit the battery's charge/discharge power via Homey Flows. An Export Limit option can fire flows on your inverter when the battery is full and still exporting.
Solar Forecast (Solcast) — Optional. Enter a free Solcast Hobbyist Resource ID + API key to get a PV forecast (today/tomorrow, up to 7 days ahead; multiple sites, e.g. east + west roof, are summed). Shown in Diagnostics → EMS Diagnostics and available as flow triggers/conditions. The Solar-forecast start gate (under Home Batteries) can hold off starting devices on a poor-forecast day, manually (kWh threshold) or adaptively (based on battery capacity + SOC).
EV Chargers — Continuous current control 6–32 A (1- or 3-phase, with automatic phase switching if supported). A built-in filter prevents rapid current ramping. Flows must be linked in Homey to set the charge current. Optionally assign a car per charger to track its SOC and set a target charge level.
Heat Pumps — On/off control via Flow. Configurable minimum surplus threshold. Measured power (W) is used to avoid rapid on/off switching.
Boilers / Pools / Dehumidifiers — Same logic as heat pumps, each with its own Start/Stop flow cards.
Priority order — Configure which device type gets surplus first: e.g. EV charger → heat pump → boiler → pool → dehumidifier. Lower-priority devices only receive what remains.
3 · Control via Homey Flows
The EMS decides when a device runs but never sends direct device commands — instead it fires Flow trigger cards that you link to your devices in Homey:
EV — Set charge current
Trigger "EMS wants to set charger current" → tokens amps, phase1/2/3, charger_device_id. Action: charger app "Set current".
EV — Start charging
Trigger "EMS wants to start charging" — fired once when charging activates (for charger apps that require an explicit Start command).
Heat pump — Start / Stop
Triggers "EMS wants to start heat pump" / "EMS wants to stop heat pump". Only fired when surplus ≥ minimum threshold.
Boiler — Start / Stop
Triggers "EMS wants to start boiler/heater" / "EMS wants to stop boiler/heater".
Pool — Start / Stop
Triggers "EMS wants to start pool pump" / "EMS wants to stop pool pump". On the first tick after app start no flows are fired (observation mode).
Dehumidifier — Start / Stop
Triggers "EMS wants to start dehumidifier" / "EMS wants to stop dehumidifier" — same solar-surplus logic as heat pumps/boilers/pool.
Air conditioner — Start / Stop
Triggers "EMS wants to start air conditioner" / "EMS wants to stop air conditioner" — same solar-surplus logic as heat pumps/boilers/pool.
Battery and inverter also have flow triggers (force charge/discharge, max power, export limit) — set them up from the Home Batteries section's Flow Actions.
4 · Set up Flow cards
Use the ✓ Create / Update Flows button in each device section — it automatically creates the required flows in the Homey folder "_Huawei EMS". You can then open the Homey app, edit those flows, and link them to your devices.
5 · Diagnostics & history
The Diagnostics section below has an EMS Diagnostics panel (live tick health, the last decision, PV forecast, and app memory usage) and an EMS History log of recent mode/device/charger events, with a Copy button for sharing.
💡 Tip — Off-peak charging: Enable Offpeak charging on the EMS device in Homey to charge EVs at full power during cheap overnight tariffs when solar surplus is insufficient. Solar surplus still takes priority when available (configurable), and weekday/weekend windows can differ.

⚡ Grid Meter▼

The EMS reads grid power from here to determine how much surplus is available. Positive = buying, negative = selling. Multiple meters are summed.

Grid import limit — whole house (load shedding)
kW · 0 = unlimited
A hard safety ceiling on TOTAL grid import (e.g. the site's main fuse rating). It works from the measured import at your grid meters — what the house still draws after solar and battery, not total consumption. Every tick the EMS starts from that reading and reduces or holds back EV charging (Instant / Always-charge / Off-peak / Price / Low-tariff — all tiers that would otherwise draw unconditionally), Home Battery force-charge, and any new heat pump / boiler / pool / dehumidifier / air conditioner start as needed to stay under this limit — EV chargers step down gracefully where possible, the other device types (on/off only) simply have their start denied if it wouldn't fit. Leave at 0 if you don't need a whole-house cap.

💶 Electricity Pricefixed▼
The current electricity price is exposed as a device value (tile, Insights, flow token). Choose the tariff model:
High-tariff time window per weekday (HH:MM). Outside the window the low tariff applies. A day with no times = low tariff all day. A window across midnight (e.g. 22:00–06:00) is allowed.
Setup: An external app (e.g. Tibber, EPEX spot, dynamic tariff) sets the current price via the flow action "EMS: set electricity price (per kWh)". The last value set is used as the current price. Can your price source instead provide a full day-ahead hourly forecast (e.g. "Power by the Hour")? Then use "Price forecast (day-ahead)" below instead — no separate flow needed for the current price.

🌤 Solar Forecast (Solcast)off▼
Free Hobbyist account at Solcast Toolkit — register your PV system with its exact details, then copy your API key (under Your name → Your API key) and Resource ID (click your site on the map). Multiple sites (e.g. north + south roof) — enter one per line; their forecasts are summed. New accounts get 10 API calls/day (older accounts 50) and each site is one call, so the app spaces fetches out automatically to stay within budget (≈ 8 calls/day total whether 1 or several sites) and caches across restarts — no flows needed. Result appears under Diagnostics → EMS Diagnostics.

🚗 EV Chargers▼
Which "Charging mode" should I pick?
Three modes below use grid power outside solar surplus — each solves it differently:
Off-peak window
When: fixed daily time window, same every day
Setup: Off-Peak Charging schedule below
Low tariff
When: whenever your Low/High weekday schedule says LOW
Setup: Electricity Price → Low / high tariff
Cheapest hours (forecast)
When: dynamically — the actual cheapest hours, per real price data
Setup: Electricity Price → Price forecast + Cars → Ready by
Rule of thumb: have real hourly price data (e.g. Power by the Hour, Tibber)? Use Cheapest hours — it's the most accurate. Only a fixed cheap/expensive schedule, no live prices? Use Off-peak window or Low tariff depending on which schedule you already maintain.

🚙 Cars▼
Add one or more vehicles. Per car, the current charge level (read from the selected device) and the target charge (set via flow) are exposed as their own device values (tile, Insights, flow tokens). Use each car's Flow setup to apply the target charge to the vehicle.
♨️ Heat Pumps▼

Add each heat pump you want EMS to control. Set the minimum solar surplus required to start it, and optionally a start delay (surplus must hold that many seconds before EMS turns it on) and a stop delay (surplus may drop for that many seconds before EMS turns it off — avoids short cycling).

🚿 Boilers / Immersion Heaters▼

Add each boiler or immersion heater you want EMS to control. Set the minimum solar surplus required to turn it on, and optionally a start delay and a stop delay to prevent rapid switching.

💧 Pool / Whirlpool▼

Add your pool or whirlpool pump. EMS will run it whenever sufficient solar surplus is available. Use the start and stop delays to avoid short on/off cycles.

💨 Dehumidifier▼

Add your dehumidifier. EMS will run it whenever sufficient solar surplus is available. Use the start and stop delays to avoid short on/off cycles.

❄️ Air Conditioner▼

Add your air conditioner. EMS will run it whenever sufficient solar surplus is available. Use the start and stop flows to switch it.
