Smart Charger (OCPP)

Connect your Huawei SCharger via OCPP 1.6 to Homey.

Setup in FusionSolar App (as Installer):
1. Open FusionSolar → Services → Device Commissioning
2. Scan the QR code on the SCharger and connect via its WiFi hotspot
3. Go to Settings → Third-party management system → OCPP Settings
4. Mode: Insecure transmission with basic authentication
5. Fill in the Comm. Parameters:
  • Domain: Homey's IP address (no ws://)
  • Port: 8887
  • Path: your Station ID (e.g. EVB-P12345)
  • Username / Password: optional — enter the same below if used
6. Save and restart the charger if prompted

The Station ID of your charger (e.g. EVB-P12345). Find it in the Huawei FusionSolar app or the OCPP settings of your wallbox. Must match exactly (case-sensitive).

Only needed if you configured authentication in the SCharger OCPP settings.
